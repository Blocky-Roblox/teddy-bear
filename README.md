# 熊熊陪你 — Teddy & You

一個支援滑鼠、觸控和鍵盤的互動泰迪熊網站。拖曳與甩動熊熊、摸摸、搔癢、擁抱、拋高高，或陪牠打盹。

## 開啟

直接用瀏覽器開啟 `index.html`。所有樣式、插圖、物理互動和合成音效都包含在檔案內，不需要安裝依賴、登入或外部素材。

也可在這個目錄執行：

```sh
python3 -m http.server 4173 --bind 0.0.0.0
```

## 操作

- 抓抓：按住熊熊任一部位，移動後放開。快速移動會甩出去。
- 摸摸／搔癢：選擇模式後，在熊熊身上按住移動。
- 按鈕：擁抱、切換搔癢、拋高高、打盹／叫醒、重置。
- 鍵盤：`1`／`2`／`3` 切換模式、空白鍵拋高高、`H` 擁抱、`R` 重置。
- 音效預設關閉，可由右上角開啟。音效由 Web Audio 產生。

網站不蒐集資料。沒有帳號、追蹤器或網路請求。互動次數只在本次開啟期間保留。

## 部署

可部署到任何靜態網站空間。GitHub Pages 使用 `main` 分支根目錄的 `index.html` 即可。
