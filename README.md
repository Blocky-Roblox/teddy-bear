# 泰迪熊 — 毛絨布偶遊樂場

一隻沒有生命的立體毛絨布偶：可以拿起耳朵、頭、手掌或腳掌，甩動、按壓、拋起，再讓它自然落下。臉上的玻璃眼睛和縫線固定在頭部，布偶的運動來自重力、施力和碰撞。

網站：https://blocky-roblox.github.io/teddy-bear/

## 開啟與開發

`index.html` 是完整的單檔成品，包含 Three.js、Cannon ES、樣式和合成碰撞音效，不依賴 CDN 或外部圖片。可以直接以支援 WebGL 2 的瀏覽器開啟，或使用靜態伺服器。

開發來源在 `src/`，Node.js 20 以上可重新建置：

```sh
npm ci --cache /tmp/teddy-npm-cache --no-audit --no-fund
npm run build
npm test
```

本機預覽時，只公開生成的 HTML：

```sh
mkdir -p /tmp/teddy-web
cp index.html /tmp/teddy-web/index.html
python3 -m http.server 4173 --bind 127.0.0.1 --directory /tmp/teddy-web
```

## 操作

- **拿起**：按住任一部位，移動再放開。各肢體獨立下垂、旋轉並傳遞力道。手機可用兩指抓住不同部位。
- **按壓**：按住布偶施力；布偶與關節順著力道移動，表面會輕微壓縮。
- **轉視角**：拖曳旋轉，滾輪或雙指縮放。
- **按鈕**：拋起、放倒、換視角、重新擺好。
- **鍵盤**：`1`／`2`／`3` 切換操作、空白鍵拋起、`R` 重置。輸入欄位與按鈕保留原生鍵盤行為。
- **柔軟度**：調整縫合關節的被動扭轉阻力和按壓形變。
- **音效**：預設關閉，開啟後播放由真實碰撞速度觸發的柔和落地聲。

## 模型與物理

12 個獨立剛體：身體、頭、兩耳、兩上臂、兩手掌、兩腿、兩腳掌。11 個 ConeTwist 關節代表布偶縫合處，配合低強度被動扭轉阻力。採固定 120 Hz 時間步長、橢球凸包碰撞、自體碰撞、摩擦、低彈性落地，以及靜止休眠。拖曳使用受力限制的關節連到手部，而非整體平移或預設的四肢動畫。

絨毛由實際延伸出表面的彎曲細纖維幾何構成；核心布面使用程序化凹凸貼圖。玻璃眼睛、鼻子、繡線、腳掌和蝴蝶結是立體模型。材質完全在本機生成，手機使用較少纖維與較低陰影解析度。偵測到 SwiftShader 等軟體渲染器時，會進一步降低纖維密度和陰影解析度，以保留操作反應；物理部件、關節與求解精度保持一致。

物理使用剛體與柔性關節近似填充布偶；表面按壓是受力驅動的視覺壓縮，並非連續體積軟體或逐根毛髮的碰撞模擬。

`npm test` 驗證自由落下與靜止、抓手傳力、耳朵與腳掌拖曳、雙指約束、關節保持連接、按壓、拋起與重置。建置會檢查實際嵌入 HTML 的 JavaScript 語法。Three.js 與 Cannon ES 的授權附在成品 HTML 中。

準備好的雲端環境也提供 Python Playwright 與 Chromium。在上述伺服器啟動後，可執行 `python3 tests/browser_smoke.py`，驗證實際畫面、部位拖曳、觸控雙指操作、按壓、視角、控制項與離線成品。其他主機需先安裝 Playwright 與 Chromium；可用 `TEDDY_TEST_URL` 指定預覽伺服器，截圖預設寫到 `/tmp/teddy-browser-checks`。軟體渲染測試使用較低像素密度，所有物理與互動檢查仍執行。

網站不蒐集資料，不需要登入或伺服器端程式。執行時沒有外部資源請求。

## 部署

`npm run build` 更新根目錄的 `index.html`。將來源與成品提交到 `main`，既有 GitHub Pages 會從根目錄發布。`.nojekyll` 保持靜態檔案的直接輸出。
